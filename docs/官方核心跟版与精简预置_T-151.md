# 官方核心跟版与精简预置（T-151）

## 1. 结论先行

1. WorkNexus-DSH 上游基线已由 `dsh-v0.2.1-rc.5` 升级到
   **`dsh-v0.2.2-rc.1`**（`66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`）。
2. 随包第三方 bundle 根只保留 **`dshmarket@1.73.14`**；运行依赖闭包只含
   `undici@7.29.1`。安装包不再携带 `dsh-better-sidebar`、`dsh-claude-style`、
   `@tt-a1i/archify-dsh`、`@linxin666/dsh-client-ui-skill-explorer`。
3. 官方默认 bundle 定义未改；Desktop profile 初值直接使用官方 Web 模板。
4. 升级机启动时只清理四个已退役的历史预置及其依赖登记，保留用户自行安装的其它 bundle。
5. 14 个差异集已在 rc.1 上重新导出；唯一路径 129 条，隔离重放与真实工作区逐字节一致。

## 7. 裁决记录

| # | 裁决：<决定> — <理由> — <错判代价> |
| --- | --- |
| T151-1 | **跟 npm `latest` 的 `0.2.2-rc.1`** — 用户要求跟随官方最新核心；`latest` 与 `next` 均指向该 tag — 若误跟 alpha 线，会扩大 API 迁移面。 |
| T151-2 | **只保留 `dshmarket` 一个第三方根** — 用户明确要求其它自行添加的 bundle 不随包安装 — 若误删官方默认 bundle，会破坏基础宿主能力。 |
| T151-3 | **迁移时精确清理四个历史预置** — 四个名字可由旧锁文件和 profile 补齐逻辑证明归属 — 若按宽泛规则清插件，会误删用户自行安装的 bundle。 |
| T151-4 | **安装器品牌文案迁移到官方 locale JSON** — rc.1 已删除静态 `strings.nsh`，新版由 locale 渲染 — 若继续补丁旧文件，安装器品牌会失效。 |
