## 1. 需求描述

企业发行版仍保留上游 `DeepSeek Harness` 品牌标识，需替换为企业品牌（WorkNexus）。
决策人指出的位置：**登录页**、**工作区左上角**；实测另发现**窗口标题后缀**。
替换范围应包括：产品名文案、名称字标（wordmark）、标志图形（官方鲸鱼 mark）。

## 2. 实测取证（2026-09-29）

| 观测点 | 证据 |
| --- | --- |
| 窗口标题 | Win32 `EnumWindows` 实测主窗口标题 `未签名 exe 被 SmartScreen 拦截 — DeepSeek Harness`（PID 43992，`Chrome_WidgetWin_1`，1295×679） |
| 安装包规模基线 | 安装后 `resources\app.asar` 内 `DeepSeek Harness` 共 **247 处** |
| 桌面壳文案 | `apps/desktop/src/locale.ts` 中 `DeepSeek Harness` 残留 **0 处**（T-021 已全覆盖，全部为 `WorkNexus-DSH`） |
| **视觉证据**（2026-09-29，决策人提供） | `内部验收证据（RM-01_主窗口工作区）`、`内部验收证据（RM-01_侧栏与更多菜单）`：侧栏左上角为上游 **`deepseek HARNESS` 字标 + 鲸鱼标志**；登录入口在 `更多 → 登录`，同样带该标识 |

**由截图补充的关键细节**：残留物**不只是文本**，侧栏/登录页用的是**图形字标（wordmark）与鲸鱼标志图形**，因此实现上必须替换图形资产，单纯改文案不够——这正好对应落点线索 #1 的 `FishLogo` / `BrandWordmark`（来自 `@deepseek-ai/dsh-client-ui-primitives`）。

结论：**T-021 覆盖的是桌面壳自身文案与图标，未覆盖客户端 UI 包（`packages/client/**`）与工具包常量**，这正是残留来源。
