# 用量报表聚合（T-049）

## 1. 结论先行

1. `GET /api/v1/reports/usage` 支持总量与按用户、空间、模型三个维度聚合。
2. 报表把 `dsh_event` 记录放入 `precise`，`adapter_estimate` / `manual_import` 放入 `estimated`，不混算。
3. Token 缺失字段保持 null，并单独输出 `unknownTokenCount`；不会用 0 代替未知。
4. 空间维度缺失时显示 `dimensionId='unknown'`，并用 `unknownCount=1` 标记缺失维度，不显示为正常空间。
5. 无数据时返回 `noData=true` 和 `message='无数据'`，不会生成空聚合伪装成 0。
6. 报表仅组织 `owner/admin` 可访问。
