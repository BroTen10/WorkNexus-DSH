# 知识库检索与空间权限过滤（T-062）

## 1. 结论先行

1. `plugins/knowledge/src/retrieve.ts` 交付 `retrieveForSpace()`：**先判定、后检索、再过滤**的三段式，满足 P3-F05「检索结果必须按空间成员权限过滤」。
2. 无权限时**不调用 Provider**：实现上 `policy.can(spaceContext, 'kb.retrieve', ...)` 位于 `provider.retrieve(...)` 之前，测试用例断言 provider 未被调用。
3. 检索后按空间归属过滤：命中的 `spaceId` 属于「项目空间 / 部门 / 组织」会话范围才保留；`allowedSpaceIds`（T-063 绑定解析结果）存在时以其为唯一允许集。
4. 未带空间标识的命中按**绑定反查**口径保留（第三方 RAG 常不返回空间字段），该假设已显式登记。
5. 检索失败一律降级：`provider.retrieve` 抛错被捕获并返回空数组，不向官方会话主链路抛未捕获异常。
6. 裁决：`allowedSpaceIds` 与 `spaceContext` 同时存在时**以绑定解析结果为准**——理由是绑定是管理员配置的权威授权，会话上下文只作缺省推导；**错判代价**是若调用方漏传绑定允许集，会退化为「按会话空间放行」，需由 T-063 保证调用方总是传入。
