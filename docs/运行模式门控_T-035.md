# 运行模式门控（T-035）

## 1. 结论先行

1. 运行模式由**当前登录态 + 组织上下文**推导：未登录或未选定组织为 `personal`；已登录且已选定有效组织为 `enterprise`。不提供手工模式开关。
2. `createModeContext()` 是纯状态投影。切换就是传入新的 `ModeProviderState`；实现不回滚、不删除官方会话与工作区数据。
3. 健康企业态：企业入口可见、控制面可连、插件治理为 `strict`、数据归属组织。
4. 个人态：企业入口隐藏、控制面不连、插件治理为 `record-only`、数据归属本地。
5. 控制面不可达或状态未知时，企业态按 fail closed 降级：官方 DSH 会话仍可用，企业入口隐藏、控制面不连、治理回落 `record-only`，并给出明确提示。
6. 组织上下文失效时退回 `personal` 并标记 `degraded`；数据归属本地，不把企业数据复制到本地。
7. `ModeProvider` 是唯一输入抽象；真实登录态投影留给 T-051 对接。此裁决与派发卡一致。
