# 核心实体与迁移（T-041）

## 1. 结论先行

1. 需求书 §6.1 的 16 个核心实体已全部建模，并可随 Alembic 迁移在 PG17 上创建与回退。
2. `AuditEvent` 与 `UsageRecord` 只有追加语义所需的字段，没有 update/delete 接口；审计更正通过 `corrects_event_id` 指向原事件。
3. 审计与用量默认留存 1095 天（3 年），包含 `retain_until`、`retention_days`、`purge_approved_by`、`purge_reason`、`purged_at`。
4. `PluginInstall.state` 只是官方 plugin-manager 状态镜像；`official_state` 与 `authoritative_source` 明确声明官方权威，不承载启停权威语义。
5. `SessionMeta` 只保存官方会话 ID 与企业归属（组织、部门、空间、用户），没有 prompt、output、transcript、messages 或正文类列。
6. 层级默认为组织 → 部门 → 项目空间；成员与角色使用显式范围字段，角色枚举与 T-030 契约一致。
