# 企业插件声明规范（T-031）

## 1. 结论先行

1. 企业插件声明落在官方 `package.json` / bundle 声明之上，不提供第二套插件装载器或生命周期。
2. 解析入口为 `parseEnterpriseDeclaration()`；官方字段（`dependencies`、`optionalDependencies`、`peerDependencies`、`dsh.bundle.patch`）原样保留，企业治理字段与官方字段可共存。
3. 权限清单直接引用 `@worknexus/contracts` 的 `Action` 枚举，避免规范和契约漂移；白名单外权限直接拒绝。
4. 兼容性入口为 `checkCompatibility()`：`dshCompatibility` 与 `hostCoreCompatibility` 均使用 semver range；不满足时返回明确 `problems`，不降级为警告。
5. `protected` 是企业侧治理信号，`true` 可判定并原样保留；其保护语义仍不能替代官方 plugin-manager 的实际保护行为。
6. 官方 plugin-manager 实际以 `peerDependencies` 做 DSH 版本预检；`dshCompatibility` 是企业声明规范的企业侧复核字段。安装仍由官方执行，本模块不替代该预检。

## 4. 未验证项与边界

**需真机复核（B 类）**

- B-1：真实企业插件包在官方 plugin-manager 安装、启用、禁用、卸载流程中的完整表现。
- B-2：官方对 `package.json` 未知企业字段的容忍性需在锁定基线安装一次真实 bundle 后复核；本任务已从上游 `peerDependencies` 预检源码确认兼容性机制，但未做真实外部安装。

**需外部输入（C 类）**

- C-1：企业插件最终命名与私有源地址仍未定稿；本包不依赖具体包名。

**超出本次范围**

- O-1：不实现插件启停、安装、卸载、版本升级或回滚；这些归官方 plugin-manager，企业侧订阅归 T-032。
- O-2：不定义 UI 槽位的官方结构；本任务仅保留 `uiSlots` 数组和非空字符串校验。
