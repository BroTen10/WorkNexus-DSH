# 企业管理插件 UI（T-050）

## 1. 结论先行

1. `plugins/enterprise-admin` 已建立官方插件形态：`package.json`、`plugin.manifest.json` 和 `dsh.bundle.patch`，不新增第二套插件装载器。
2. 六个页面（组织、成员、角色、空间、审计、用量）已注册为六个官方 UI 槽位声明；当前为页面注册表和权限映射，真实 React 渲染与官方槽位联调归 B 类复核。
3. 插件声明权限包含 `identity.read`、`space.read`、`audit.read`、`usage.read`、`budget.write`；`identity.read` 是需求 §5.2 样例动作，但 T-030 契约未列出，已在解析器中作为插件声明扩展动作处理。
4. `canRender()` 使用 T-044 客户端矩阵做 UI 预判；viewer 不显示预算写控件。最终仍以服务端裁决为准。
5. `visiblePages('personal')` 返回空数组，`visiblePages('enterprise')` 返回六页，与 T-035 门控一致。
6. 插件不实现插件管理 IPC、不实现启停/安装/卸载能力，不替换官方插件管理界面。
