# 控制面骨架（T-040）

## 1. 结论先行

1. `services/api` 已建立 FastAPI 控制面骨架：`GET /api/v1/health` 返回服务状态、数据库状态和版本。
2. 技术栈固定为 FastAPI + SQLAlchemy 2 + Alembic + PostgreSQL 17 + Pydantic Settings；测试框架为 pytest。
3. JWT 采用零第三方依赖的 HS256 实现，分 Access / Refresh Token；企业 Token 只服务企业控制面。
4. 边界已固化：企业控制面只服务企业资源，不接管官方 `packages/api` 会话链路；两者鉴权独立，官方会话不带企业 Token。
5. PG17 通过 Docker Compose 提供宿主映射 `15432 -> 5432`，端口与默认开发密码只写在 `.env.example`，代码不硬编码连接串。
