### 裁决

- **裁决 T148-1：直接取 npm 稳定版 `latest`。** — 理由：用户要求市场和全部预置插件按最新版重打包；两个目标均为稳定版而非 prerelease。 — 错判代价：引入 0.18.1 的新界面/行为变化。
- **裁决 T148-2：保持 5 个根、88 个 tgz 的包集口径。** — 理由：两个升级都没有新增依赖，闭包未扩张；数量减少会说明漏包，增加会说明依赖漂移。 — 错判代价：若上游后续增加依赖，必须重新登记闭包。
- **裁决 T148-3：继续沿用 T-147 的市场外置布局。** — 理由：新市场版本只替换运行时内容，不改变“市场不进入 profile `node_modules`”的稳定性边界。 — 错判代价：升级安装包仍需覆盖安装并重启。
