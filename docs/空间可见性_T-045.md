# 私有空间可见性与默认拒绝（T-045）

## 1. 结论先行

1. 项目空间列表和详情统一接入可见性过滤；`owner` 可见组织内全部空间，其他用户必须拥有显式项目空间 RoleAssignment。
2. 未授权成员的空间列表返回空数组，空间详情返回 404；组织不存在仍返回 404，普通成员不会从列表获得组织存在性线索。
3. 个人模式通过 `X-WorkNexus-Mode: personal` 强制返回空列表，详情一律 404；不会返回任何企业空间。
4. 未授权访问空间详情写入 `space.read` 且 `result='denied'` 的审计，记录空间 ID 和用户。
5. 空间授权路由改为 owner/admin 指定目标用户；成员不能给自己授权，修复了初版实现的越权点。
6. 跨组织访问按 404 处理而非 403，避免泄漏资源存在性。
