## 4. 裁决记录

| # | 裁决：<决定> — <理由> — <错判代价> |
| --- | --- |
| R-1 | 锁定 `dsh-v0.2.0-rc.1` 而非等待稳定版 — 总览 §2.1 第 1 条「锁定最新已发布 tag」；当前全部 release 均为 prerelease，等待稳定版会使批次 1 无限期阻塞 — 若 rc 版本存在严重缺陷，回退到 `dsh-v0.1.7-rc.2`（代价：一次 rebase 演练） |
| R-2 | 接受「壳与 dsh 版本恒等 + 三者同签名单元」 — 需求书 §3.4 锁定口径原文 — 若违反，更新后会出现壳与内核不匹配的不可诊断故障 |
| R-3 | 回退目标固定为 `dsh-v0.1.7-rc.2` — 它是锁定版之前最近的一个 rc，且本机 第三方 参照为 0.1.7-alpha.2（同 0.1.7 段），生态兼容性最好 — 若该 tag 也存在问题，回退空间进一步收窄（风险见 §5） |
| R-4 | 不锁 `master` 快照作为基线 — 分支会前进，无法复现；与 T-001 R-1 一致 — 若误锁分支，全部差异集行号与 rebase 基线失真 |
