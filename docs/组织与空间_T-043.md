# 组织、部门与项目空间（T-043）

## 1. 结论先行

1. 已实现组织、部门、项目空间的创建、查询、更新与归档接口，层级默认为组织 → 部门 → 项目空间。
2. 创建组织的用户自动获得 `owner` 角色和组织级 Membership；组织更新与所有权转移仅 `owner` 可执行。
3. 部门和项目空间的管理操作要求组织内至少 `admin`；未授权成员访问一律返回 404，不泄漏存在性。
4. 组织、部门、空间的创建、更新、归档和所有权转移均写入审计。
5. 归档使用状态字段而非物理删除，便于追溯和恢复；当前不提供硬删除业务接口。
6. 最小审计查询 `GET /api/v1/audit` 已提供，供 T-043 自证；完整九类事件、导出、留存与清理在 T-046 补齐。
7. 裁决：层级固定三级，第一版不做任意层级组织树；软删除用 `archived`，不做硬删除。
