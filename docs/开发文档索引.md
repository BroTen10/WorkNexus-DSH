# 开发文档索引

> **适用范围**：本索引面向**公开发布仓库**。
>
> 企业内部的过程记录——任务拆分总览、派发卡/任务卡、拆分检查报告、步骤明细附录、执行账本、真机验收操作清单与执行记录、验收证据、准入评审、演练与迁移记录、预检记录、历史归档——**不随公开发布**。正文中若出现「内部 XXX」字样，即指上述文档。

## 4. 维护约定

- 文档类型新增（`docs/技术决策-*.md`、`docs/<任务名>_T-<xxx>.md`）时同步补入本表。
- 交付说明必须六段齐备；验证证据表只写实测结果，不写"预计"。
- 上游 diff 只允许落在需求说明书 §3.4 白名单内，`git diff --stat` 与差异集清单不一致即视为任务失败。
