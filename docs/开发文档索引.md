# 开发文档索引

> **适用范围**：本索引面向**公开发布仓库**。
>
> 企业内部的过程记录——任务拆分总览、派发卡、拆分检查报告、步骤明细附录、执行账本、真机验收操作清单与执行记录、验收证据、准入评审、演练与迁移记录、历史归档——**不随公开发布**。正文中若出现「内部 XXX」字样，即指上述文档。

## 文档分层

| 层 | 内容 | 用途 |
| --- | --- | --- |
| ① 基线 | 需求说明书 v1.2、差异集清单、HostCore 契约、待办需求 | 实施与验收依据 |
| ② 决策 | `docs/技术决策-*.md` | 关键选型的证据、结论与裁决 |
| ③ 交付 | `docs/<任务名>_T-<编号>.md` | 每个任务的结论先行 / 改动清单 / 验证证据 / 边界 / 复现命令 / 下一步 |
| ④ 门禁 | `scripts/verify_t*.py`、`scripts/check_task_split.py` | 可复跑的机器判据 |

## 3. 交付说明

命名约定：`docs/<中文任务名>_T-<编号>.md`，固定六段——结论先行 / 改动清单 / 验证证据表 / 未验证项与边界 / 复现命令 / 下一步。未验证项按「需真机复核（B 类）/ 需外部输入（C 类）/ 超出本次范围」三分。

索引按阶段分组：

| 阶段 | 任务编号区间 | 主题 |
| --- | --- | --- |
| P0 上游对齐与 P1 企业发行版 | T-000 ~ T-029 | 工程基线、上游构建基线、品牌差异集、更新与签名、企业 bundle 预置、入口挂载、诊断脱敏 |
| P2 HostCore 与企业管理 | T-030 ~ T-054 | 契约骨架、事件通道、运行模式、控制面、组织/成员/权限/空间、审计、用量、预算、报表、企业管理 UI |
| P3~P6 业务插件 | T-060 ~ T-105 | 知识库、文档审查 Adapter、IPD、ACP、插件市场治理、后台任务 |
| 批次 9 收尾 | T-106 ~ T-108 | 发行物打包集成、客户端品牌残留与打包冒烟、客户端回归门禁 |

## 4. 门禁与脚本

| 脚本 | 用途 |
| --- | --- |
| `scripts/check_task_split.py --stats` | 任务拆分自洽门禁（8 项，退出码 0 为通过） |
| `scripts/verify_t<编号>_<域>.py` | 单任务真机门禁：先探活再跑探针，逐项 `[OK]`/`[FAIL]`，出现任一 `[FAIL]` 退出码为 1 |
| `scripts/pack_enterprise.py` | 企业层打包（tgz） |
| `scripts/package_desktop_win_unsigned.py` | Windows 未签名安装包规范出包入口（含出网镜像注入） |

## 5. 维护约定

- 文档类型新增（`docs/技术决策-*.md`、`docs/<任务名>_T-<xxx>.md`、`docs/HostCore契约-v1.md`）时同步补入本表。
- 交付说明必须六段齐备；验证证据表只写实测结果，不写"预计"。
- 上游 diff 只允许落在需求说明书 §3.4 白名单内，`git diff --stat` 与差异集清单不一致即视为任务失败。
