# 插件安装审计与安全提示（T-104）

## 1. 结论先行

1. `plugins/market/src/risk-display.tsx` 交付 `<RiskDisplay>`：展示**权限清单、来源、最近更新时间与风险等级**（P6B-F06）。
2. 风险等级按三项规则判定（裁决）：权限范围（敏感权限数量）+ 来源可信度（`local`/`official` 可信、`private-registry` 需自评）+ 最近更新（>180 天视为陈旧）；缺少可解析时间同样上调风险。
3. 组件**始终渲染来源与全部权限项**，不因风险等级隐藏信息（T-104 禁止事项），并以 `data-sensitive` 标出敏感项。
4. 安装/更新/启停审计齐备（§6.2 第 4 类、P6B 验收 3）：`plugin.install`（安装闸口）、`plugin.update`（升级放行）、`plugin.enable` / `plugin.disable` / `plugin.uninstall`（T-032 治理钩子）均在审计白名单内并有落库路径。
5. 裁决：风险等级采用「三项规则打分」而非单一维度 — 理由是权限范围之外，来源与陈旧度对企业安全评审同样关键 — 错判代价：阈值（≥1 → 中、≥3 → 高、180 天）为经验值，若企业口径不同需调整常量并回归。
6. 裁决：不引入第三方评分服务 — 理由是 P6B 只要求「显示权限、来源、风险和最近更新信息」，外部评分会引入新的外部依赖与隐私面 — 错判代价：评分粒度较粗，复杂供应链风险需人工评审。
