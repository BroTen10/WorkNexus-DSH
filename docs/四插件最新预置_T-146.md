### 裁决

- **Archify 进入预置** — 用户明确要求“当前运行中的 4 个插件全部随包”；Archify 是 Skill 提供器且无额外运行依赖，应加入 bundle 与依赖锚点 — 错判代价：不加入则新机/清 profile 后缺少该插件。
- **四插件保持“Claude Style → Archify → Skill Explorer → Better Sidebar”顺序** — Better Sidebar 的聚合 bundle 守卫在前面的条目中查找同名插件，放最后可避免重复挂载 — 错判代价：若前置聚合条目存在，可能重复注册 `/sidebar/api`。
- **`dsh-market` 暂留 1.66.42** — 1.66.44 的差异集中在更新链路和日志脱敏，不是本次四插件收录的阻塞项；用户也已说明昨天刚升级、暂不扩改动 — 错判代价：后续遇到更新回滚/镜像提示时仍需单独跟到 1.66.44。

```powershell
python scripts\package_desktop_win_unsigned.py
$installer = 'repos\deepseek-harness\apps\desktop\.desktop-build\targets\win-x64\unsigned-artifacts\worknexus-dsh-0.2.1-rc.2-win-x64-unsigned.exe'
Start-Process -FilePath $installer -ArgumentList '/S' -Wait

# 4) 宿主激活与侧栏路由
$ids = (Get-Process WorkNexus-DSH).Id
$port = Get-NetTCPConnection -State Listen |
  Where-Object { $ids -contains $_.OwningProcess } |
  Select-Object -First 1 -ExpandProperty LocalPort
curl.exe -s -o NUL -w "%{http_code}`n" -X POST "http://127.0.0.1:$port/sidebar/api/fs.read" `
  -H "content-type: application/json" -d "{}"
```
