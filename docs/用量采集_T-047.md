# Token 用量采集与记录（T-047）

## 1. 结论先行

1. `packages/kernel-dsh/src/usage.ts` 将官方 session 投影映射为 `UsageRecord`：缺失字段一律 `null`，不填 0。
2. 来源固定为 `dsh_event` / `adapter_estimate` / `manual_import`；`precise: false` 标记为 `adapter_estimate`。当前官方账号能力不可用，来源以官方 session 投影为主。
3. `POST /api/v1/usage` 按 `usageId` 幂等去重；重复提交返回既有记录，不追加、不更新。
4. 用量模型和路由没有 update/delete；`GET /api/v1/usage` 显式返回 `estimatedCount`，区分估算/导入记录。
5. `packages/host-core/src/usage-ledger.ts` 提供 HTTP `UsageLedger` 薄适配，仅暴露 record/query，与 T-030 契约一致。
6. 用量写入会写入 `usage.record` 审计，但不记录 prompt、模型输出或凭据。
