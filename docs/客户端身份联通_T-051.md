# 客户端身份联通控制面（T-051）

## 1. 结论先行

1. `packages/host-core/src/identity.ts` 实现企业登录态提供器：`signIn`、`signOut`、`refresh`、`current`。
2. 登录成功后 Refresh Token 写入注入的 `SecureStore`；真实实现必须绑定官方凭据服务适配器，本任务不创建第二套本地凭据存储。
3. 控制面不可达或 Refresh Token 失效时，身份回落 `personal`，记录明确提示“DSH 会话仍可用”，不阻塞官方客户端。
4. 已登录且控制面返回组织上下文时，`IdentityContext.mode='enterprise'`；未登录或无组织时为 `personal`。
5. `buildOfficialSessionHeaders()` 永远不携带企业 Token；`hasEnterpriseTokenInOfficialSession()` 恒为 false，固化官方会话边界。
6. `apps/desktop/src/main/auth/session.ts` 是主进程装配占位，声明控制面地址与官方凭据适配器；真实 Electron 联调归 B 类。
