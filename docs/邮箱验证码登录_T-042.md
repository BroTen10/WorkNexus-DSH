# 邮箱验证码注册与登录（T-042）

## 1. 结论先行

1. 已实现 `POST /api/v1/auth/code`、`/register`、`/login`、`/refresh`，满足 P2-F01 的邮箱验证码注册与登录。
2. 验证码只保存 SHA-256 哈希，不保存明文；请求/响应、路由日志和测试日志断言都不包含验证码。
3. 验证码有效期、重发节流和错误次数限制集中在 `Settings`；默认 10 分钟有效、60 秒重发节流、5 次错误限制。
4. 密码使用标准库 `hashlib.scrypt` 加盐哈希，不落明文；日志中间件只记录方法、路径、状态和耗时。
5. 邮件通道使用可注入 `EmailSender` 协议；真实邮件服务尚未接入，测试用测试发件器注入。
6. 验证码请求、注册、登录和密码失败均写入审计；审计不记录密码或验证码。
7. 裁决：验证码请求先创建占位 User，用于关联验证码；注册在同一用户上设置正式密码。真实邮件通道与防滥用风控为待办。
