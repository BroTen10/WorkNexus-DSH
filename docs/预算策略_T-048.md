# Token 预算与阈值阻断（T-048）

## 1. 结论先行

1. 已实现组织、部门/项目空间、用户三层预算策略数据面；本任务先激活组织级评估，空间与用户策略字段已就位。
2. 预算评估按当月 `estimated_cost` 累计；无策略时状态为 `ok`，限额返回 null，不把“未配置”当作 0 限额阻断。
3. 软阈值返回 `soft`，调用方可提示；硬阈值阻断只作用于“新建/提交”动作，不中断已运行会话。
4. `POST /api/v1/sessions` 是企业预算闸门：硬阈值返回 HTTP 402，`reason=budget_exceeded`，并给用户可读中文提示。
5. 预算策略创建/变更写入 `budget.update` 审计；消耗通过 T-047 的用量记录进入账本。
6. 裁决：硬阈值只阻断新建/提交，不中断运行中的官方 DSH 会话；成本与 token 分开语义，本实现用成本聚合评估。
