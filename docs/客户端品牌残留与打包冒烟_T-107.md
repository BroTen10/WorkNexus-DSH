## 7. 裁决记录

| # | 裁决：<决定> — <理由> — <错判代价> |
| --- | --- |
| B-1 | **产品名抽成独立模块 `desktop-product-name.mjs`，而不是让冒烟脚本 import electron-builder 配置** — 配置模块 import 了 electron-builder 相关实现，构建期工具脚本不应因此被拖入；独立常量模块零依赖 — 若直接 import 配置，冒烟脚本会耦合打包工具链。**S5 追加**：按本仓库既有约定补同名 `.d.mts` 声明（同目录 20+ 个 `.mjs` 均如此），否则 `tsc -b` 报 TS7016 — 若省掉声明，出包在第一步即失败（本轮实测） |
| B-2 | S4 先于 S1~S3 落地并单独提交 — 它独立可验，且能让打包命令的末步恢复 — 若一并做，出包验证要等到品牌替换全部完成，问题定位面变大。**S5 更正**：单跑冒烟（tsx）不经过类型检查，**不能**替代端到端出包 |
